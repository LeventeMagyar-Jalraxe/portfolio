# Project Lighthouse 2.0

Static GitHub Pages portfolio for Magyar Levente (Jalraxe).

## Publish
1. Back up the current repository.
2. Upload the contents of this folder to the repository root.
3. Keep GitHub Pages configured for the `main` branch and `/ (root)`.
4. Open the site in a private window after deployment.

## Editing
- Main page: `index.html`
- Visual design: `css/style.css`
- Language and interactions: `js/main.js`
- Featured work pages: `works/`
- Images use lower-case, hyphenated file names.

## Notes
The opening animation runs once per browser tab/session and can be skipped. English is the default language; HU/EN changes the complete visible page content and is remembered locally. On smaller screens the main navigation is available from the menu button.

The portfolio images are resized and compressed for web delivery. The three formerly large PNG artworks use WebP while keeping their transparency and visual detail.

- Guardians of Light detail text and conservation links are stored in `js/main.js` under `guardianDetails`.
